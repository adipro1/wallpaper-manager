Wallpaper Manager 2.2 lets you make the app your own color. Your library, playlists, schedule and settings carry over.

## New
- **Accent color**: Settings > Appearance now has nine colors (vermilion, amber, gold, jade, teal, ocean, indigo, violet, rose) or any color you like with "Custom color…". Buttons, switches, highlights and the page ribbon follow it in light and dark mode; text on the color stays readable.
- **Title bar**: the window's title bar is no longer plain white. It takes the sidebar's dark indigo, with light buttons, so the whole window matches (the picker windows too).

## Install
Download `WallpaperManager-2.2.0-setup.exe` (no administrator rights needed) or the zip. If you have 2.1, you can also click "Install now" in Settings. Installing over an older version keeps your data.

## Tested
Windows 11 23H2: the unit and UI tests, plus a test that colors a real window's title bar and checks the pixels on screen. The colored title bar needs Windows 11; on Windows 10 only the caption buttons turn light.
